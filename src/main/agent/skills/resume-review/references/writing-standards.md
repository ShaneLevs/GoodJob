# 简历改写标准

## 一、STAR 的压缩写法

简历不是面试稿，每条只保留能证明能力的最小信息：

- **S 情境**：一句话交代业务背景和规模。
- **T 任务**：要解决的问题或目标。
- **A 行动**：你具体做了什么、用了什么方法。
- **R 结果**：数字、规模、前后对比、可验证的影响。

示例：

- 空泛：负责公司电商平台的用户增长，取得了不错的效果。
- STAR：主导新用户转化优化（S/T），重做注册链路并上线 15 轮 A/B 测试（A），注册转化率从 15% 升到 28%，获客成本下降 30%（R）。

不同类型用不同压缩方式：

- 日常职责：职责 + 行动 + 结果，一条一句。
- 项目：背景一句、动作两句、结果一句。
- 亮点：结果先行，再补做法。

### 动词

优先：主导、搭建、推动、重构、设计、牵头、落地、优化、谈判、交付、复用。

避免：参与、配合、协助、负责一些、做一些、跟进一下。

如果确实只是参与者，如实写「参与」，但补上你负责的那一块和产出。

## 二、关键词与 ATS

### 2.1 关键词从哪来

- 硬技能：JD 里点名的工具、技术、平台、证书。
- 职能词：用户增长、需求分析、渠道拓展、成本核算、招聘交付。
- 行业词：DAU、GMV、ROI、转化率、复购、SLA、合规。
- 方法词：A/B 测试、敏捷、OKR、精益、六西格玛。

### 2.2 怎么放

1. 专业技能栏：放 JD 要求且你确实掌握的。
2. 工作经历：在职责描述里自然出现，不单独列关键词清单。
3. 项目经历：在动作和结果里带上工具与方法名。
4. 个人优势：只概括最核心的 2-3 个，不重复堆词。

同义词用招聘方常用的写法（如 JD 写「数据分析」，就不要只写「数据洞察」），但不要为了匹配把不会的东西写进去。

### 2.3 格式与解析

- GoodJob 的简历是 Markdown，投递时按平台要求导出 PDF 或复制文本。
- 关键信息（姓名、电话、邮箱、岗位）不要只放在图片或复杂表格里，部分平台解析不到。
- 时间格式统一，章节标题用常见叫法（工作经历、项目经历、教育背景、专业技能）。
- 一页优先；两页时保证第一页有最重要的经历。

## 三、成果量化

### 3.1 可量化的维度

| 类型 | 指标 |
| --- | --- |
| 增长 | 用户数、营收、GMV、转化率、复购率、市场份额 |
| 效率 | 处理时长、交付周期、自动化率、人均产出 |
| 成本 | 成本下降比例、节省金额、资源利用率 |
| 质量 | 故障率、投诉率、返工率、满意度、NPS |
| 团队 | 团队规模、培养人数、招聘周期、离职率 |
| 风险 | 合规率、审计结果、事故次数 |

### 3.2 句式

- 动作 + 对象 + 结果：搭建区域培训体系，覆盖 120 家门店，复购率提升 9 个百分点。
- 方法 + 结果：通过重做注册链路，把转化率从 15% 提到 28%。
- 从 X 到 Y：6 个月内把平均交付周期从 14 天压到 5 天。
- 规模 + 角色：管理 8 人团队，同时推进 3 条业务线。

### 3.3 没有数字时

按可信度依次使用：

1. 范围：服务 200+ 客户、覆盖 5 个省份。
2. 对比：投诉量减半、返工减少。
3. 可验证事实：被采纳为部门标准、复用到 3 个团队、获年度优秀项目。
4. 定性：客户反馈明显改善（最后才用，尽量带场景）。

估算值写「约」，不要把猜测写成精确数字。

## 四、按公司类型调整

| 维度 | 大厂 | 中小企业 | 初创 |
| --- | --- | --- | --- |
| 看重 | 体系化、规模、方法论 | 端到端落地、直接产出 | 从 0 到 1、多角色、抗压 |
| 写法 | 强调量级、复杂度、沉淀 | 强调全流程负责、结果数字 | 强调搭建、补位、快速迭代 |
| 避免 | 只写执行细节 | 过度方法论、空话 | 只写大公司流程 |

## 五、常见雷区

### 内容

- 超过两页、重点不突出 → 删旧经历、合并同类项。
- 只有职责没有结果 → 每条补结果。
- 与目标岗位无关 → 删减或后移。
- 时间线断裂或重叠 → 如实修正。
- 编造经历或数字 → 绝对禁止。

### 表述

- 「负责 XX 工作」→ 换成具体动作和结果。
- 「取得了良好效果」→ 换成指标。
- 「大量」「很多」「部分」→ 换成范围或数字。
- 被动语态 → 改成主动。
- 口语化 → 改成书面、具体的表述。

### 结构

- 章节顺序与岗位不匹配 → 最相关的放前面。
- 技能平铺 → 分层。
- 个人信息过多 → 只留联系方式与求职意向。
- 照片、图标、颜色过多 → 交给主题，正文保持简洁。

## 六、各模块要点

- **基本信息**：姓名、求职意向、电话、邮箱、城市；链接只放相关的。
- **专业技能**：按 JD 相关度排序，分层写，不夸大。
- **工作经历**：公司 / 职位 / 时间 / 职责范围 / 3-5 条成果；最近一段最详细。
- **项目经历**：2-4 个最相关的；写清角色、动作、结果、规模。
- **教育背景**：学校、专业、学历、时间；应届生可展开，职场人压缩。
- **证书与其他**：只放相关的；写全称和时间。
- **个人优势**：真有差异化才写，3 条以内，每条有事实。
