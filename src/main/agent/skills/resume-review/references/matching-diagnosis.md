# 履历对标诊断框架

## 一、逐项映射

把 JD 拆解出的每一项要求列为评估项，在简历里找对应证据：

| JD 要求 | 层级 | 简历对应 | 匹配度 | 差距 | 处理 |
| --- | --- | --- | --- | --- | --- |
| 3 年以上 B 端销售 | 🔴 | 5 年渠道销售 | ✅ 高 | 无 | 突出年限与客户类型 |
| 数据分析 | 🔴 | 提过报表，但无结果 | ⚠️ 中 | 成果未量化 | 补指标或场景 |
| 从 0 搭建团队 | 🟢 | 未提及 | ❌ 缺失 | 确实没有 | 不硬编；用相近经历替代说明 |

## 二、匹配度评级

| 评级 | 标准 | 处理 |
| --- | --- | --- |
| ✅ 高 | 有明确、充分的经历和结果 | 直接突出，放显眼位置 |
| ⚠️ 中 | 有相关经历，但表述不足或结果没量化 | 补细节、补结果、换行业用词 |
| 🔻 低 | 只有间接相关经历 | 挖掘可迁移能力，重新表述 |
| ❌ 缺失 | 完全没有 | 有就补，没有就列为待提升；不编造 |

## 三、总体匹配度（估计值）

| 层级 | 权重 | 单项得分 |
| --- | --- | --- |
| 🔴 基础必备 | 50% | 高 100 / 中 60 / 低 30 / 缺失 0 |
| 🟡 进阶加分 | 30% | 同上 |
| 🟢 差异化竞争 | 20% | 同上 |

```
总体匹配度 = 必备项平均分 × 50% + 加分项平均分 × 30% + 差异化项平均分 × 20%
```

等级参考：

| 分数 | 含义 |
| --- | --- |
| 80-100 | 高度匹配，可以直接投 |
| 60-79 | 基本匹配，改完再投 |
| 40-59 | 部分匹配，需要重点补短板 |
| 0-39 | 匹配度低，考虑换岗位或先补硬技能 |

说明：

- 这是估计值，不是后台「简历评估」的分数；给分时说清口径。
- 必备项缺失时，总分再高也要在结论里单独提醒。
- 只有一条 JD 时，权重按这条 JD 的要求分配，不要套用别的岗位。

## 四、短板类型与处理

| 类型 | 特征 | 能不能改 | 处理 |
| --- | --- | --- | --- |
| 表述型 | 有经历，但写得空、没数字、缺关键词 | 能 | 重写条目、补结果、用 JD 用词 |
| 经验型 | 缺某项核心经验，但有相近经历 | 部分能 | 挖掘可迁移能力，换角度呈现 |
| 硬技能型 | 缺证书、学历、年限 | 短期不能 | 如实呈现，列为待提升，不伪造 |

优先级：

1. 必备项里的表述型短板（改完就能达标）。
2. 加分项里的表述型短板（低成本高收益）。
3. 差异化项里的表述型短板。
4. 必备项里的经验型短板（找可迁移证据）。
5. 硬技能短板（如实标注）。

## 五、冗余项

符合以下任一条件就考虑删减或后移：

- 与目标岗位核心职责无关。
- 太久远（10 年以上）且与当前方向无关。
- 重复表达同一件事。
- 过于琐碎的日常事务。
- 只体现「很忙」，不体现结果。

处理方式：

| 程度 | 做法 |
| --- | --- |
| 完全无关 | 删除 |
| 弱相关 | 压成一行 |
| 可迁移 | 用目标岗位的语言重写后保留 |
| 重复 | 合并去重 |

## 六、跨行业能力迁移

### 6.1 通用可迁移能力

| 能力 | 可迁移到 |
| --- | --- |
| 分析与问题拆解 | 需要决策、诊断、优化的岗位 |
| 沟通与跨部门协作 | 任何需要协作的岗位 |
| 项目管理 | 项目制、交付型岗位 |
| 快速学习 | 跨行业求职的核心能力 |
| 执行与结果交付 | 结果导向的岗位 |

### 6.2 转化示例

- 原：「负责区域销售，完成月度目标」
- 转：「调研区域客户需求，年访谈 200+ 客户，把高频需求反馈给产品，推动 3 个功能上线，区域续约率提升 15%」

- 原：「负责办公室日常行政事务」
- 转：「统筹办公区运营，优化 5 项审批流程，把平均响应时间从 2 天压到半天」

- 原：「教授 XX 课程，批改作业」
- 转：「独立设计 XX 课程体系，覆盖 500+ 学员，考核通过率提升 20%」

转化只换表达和视角，事实、数字、角色不能变。

### 6.3 跨行业结构

- **能力前置**：先写个人优势（可迁移能力），再写工作经历。
- **重点转移**：弱化行业术语，强化通用能力和结果。
- **桥梁项目**：把自学项目、副业、跨界协作项目单独展开，证明你已经在目标领域实践过。
