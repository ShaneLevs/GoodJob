# 面试准备细则

## 一、岗位分析

先回答三个问题：

1. 这个岗位每天做什么？
2. 最难的 20% 是什么？
3. 团队为什么现在招人（扩张、替换、新业务）？

把这些写进话术开头，面试时用于对齐，不要直接背给面试官听。

### 能力映射

| JD 要求 | 简历证据 | 风险 | 准备 |
| --- | --- | --- | --- |
| 例：从 0 搭建渠道 | 2022 年新签 46 家 | 缺少体系化方法 | 准备渠道分层与 SOP 的细节 |
| 例：数据分析 | 会用 SQL，但没提业务结果 | 可能被追问指标口径 | 准备一个用数据改决策的案例 |

## 二、问题清单

### 2.1 专业 / 技术

- 你在这个项目里具体负责哪一部分？离开你这件事会怎样？
- 为什么用这个方案？还考虑过什么？为什么没选？
- 指标怎么定义的？数据从哪来？有没有偏差？
- 遇到的最大技术 / 业务难点是什么？怎么定位的？
- 如果规模扩大 10 倍，哪里会先出问题？
- 你写过 / 做过最满意的东西是什么？重新做会怎么改？

### 2.2 行为

- 讲一次你和同事 / 上级意见不合的经历。
- 讲一次失败或没达标的经历。
- 讲一次时间紧、资源不够的经历。
- 讲一次你说服别人或推动跨团队的经历。
- 讲一次你带人 / 培养别人的经历。
- 你收到过最尖锐的反馈是什么？

### 2.3 情境

- 同时有三个紧急需求，你怎么排？
- 上线前发现关键问题，但老板要求按时发，你怎么做？
- 需求方说不清要什么，你怎么推进？
- 团队成员状态不好，交付受影响，你怎么处理？
- 你发现一个长期存在的流程问题，但没人愿意改，你怎么办？

### 2.4 动机与稳定性

- 为什么离开上一家？
- 为什么选我们公司 / 这个岗位？
- 未来三年想做什么？这个岗位怎么帮你？
- 你期望的薪资是多少？
- 你还有什么问题问我们？

## 三、答案框架

### 3.1 主张 + 证据 + 结果

> 我最擅长的是把模糊需求落成可执行的方案（主张）。上一份工作里，业务方只说要「提升复购」，我拆成新客首购、老客唤醒、流失召回三条线，先做小范围测试（证据）。三个月后复购率从 18% 提到 24%（结果）。

### 3.2 STAR

- S：一句话背景和规模。
- T：你要解决的问题。
- A：你做了什么，重点是你的判断和动作。
- R：结果，带数字或对比。

控制在 60 秒内。面试官追问再展开。

### 3.3 失败题

> 背景一句 → 我的责任一句 → 怎么发现 → 怎么补救 → 后来建立了什么机制。

不要：把失败说成成功、甩锅给同事、说「我没有失败过」。

### 3.4 冲突题

> 分歧是什么 → 双方立场 → 你怎么理解对方 → 用什么事实 / 试验推进 → 结果 → 关系怎么维护。

重点展示你处理分歧的方式，不是证明你对。

### 3.5 反问

问能帮你判断「要不要去」的问题：

- 这个岗位入职后前三个月最重要的目标是什么？
- 团队现在最大的挑战是什么？
- 这个岗位向谁汇报？团队规模多大？
- 绩效怎么评估？成功标准是什么？
- 这个岗位为什么空出来？

不问：官网能查到的、薪资福利细节（留到 HR 面）、「我表现怎么样」。

## 四、自我介绍

### 1 分钟版

1. 现在的身份与年限（一句）。
2. 两段最相关的经历，每段一句结果。
3. 为什么这个岗位（一句）。

### 3 分钟版

1. 开场：身份 + 一句话定位。
2. 第一段经历：职责范围 + 一个代表项目 + 结果。
3. 第二段经历：同上，体现成长或能力补齐。
4. 最近在做的事 / 学习方向。
5. 落到岗位：我能解决你们的什么问题。

不要从大学开始讲；不要复述简历每一行。

## 五、公司与行业调研

有资料时提炼：

- 公司业务、产品、商业模式、规模、融资 / 上市状态。
- 近期动态：新产品、组织调整、财报、行业新闻。
- 团队与岗位：汇报线、团队规模、业务阶段。
- 面试评价：公开面经里的流程、题型、关注点。

没有资料时列出待查清单，让用户自己补；不要编造「公司最近发布了 XX」。

## 六、薪资谈判

### 6.1 准备

- 市场区间：同城市、同岗位、同年限的 3-5 个样本。
- 自己的底线：现金、总包、期权、福利，哪些可谈。
- 当前 package 的构成：base、奖金、补贴、股票。

### 6.2 话术

- 被问期望薪资：先问岗位预算区间；必须给时说一个区间，下限是你的可接受线。
- 拿到 offer 后：先确认总包构成，再谈缺口；用市场数据和岗位职责做依据，不用「另一家给了多少」施压。
- 谈不拢时：争取签字费、试用期全薪、职级、远程 / 弹性、年假等非现金项。

不替用户决定接受或不接受；把取舍摆清楚。

## 七、面试礼仪与流程

- 提前 5-10 分钟到；线上面试提前测试网络、摄像头、麦克风。
- 准备 2-3 个问题，面试官问「你有什么问题」时不要说自己没有。
- 回答前可以停 2 秒组织语言，不要抢话。
- 不会的问题如实说「这块我没有直接经验，我的理解是……」，不要硬编。
- 面试后 24 小时内发一封简短的感谢邮件，提一个面试中聊到的具体点。
